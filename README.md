# Pokemon Trainer Portfolio 🎮⚡

Website portofolio bertema Pokemon yang modern, dibangun dengan Next.js, TypeScript, TailwindCSS, dan PostgreSQL. Dilengkapi dengan panel admin lengkap untuk mengelola konten dengan sistem CRUD.

## 🎯 Fitur-Fitur

### Website Publik
- **Desain Bertema Pokemon** - Tampilan unik ala Pokemon trainer
- **Tampilan Responsif** - Desain yang responsif untuk semua perangkat
- **Konten Dinamis** - Semua konten dikelola melalui database
- **Bagian-Bagian:**
  - Beranda dengan Kartu Trainer
  - Tentang Saya
  - Keahlian dengan progress bar
  - Riwayat Pendidikan
  - Galeri Proyek
  - Formulir Kontak

### Panel Admin
- **Autentikasi Aman** - Login admin berbasis JWT
- **Operasi CRUD Lengkap:**
  - Mengelola Profil/Info Trainer
  - Mengelola Keahlian
  - Mengelola Pendidikan
  - Mengelola Pengalaman
  - Mengelola Proyek
- **Dashboard Analitik** - Lihat statistik konten

## 🛠️ Teknologi yang Digunakan

### Frontend
- **Next.js 14** (App Router)

- **TailwindCSS**
- **Lucide React Icons**
